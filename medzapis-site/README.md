# МедЗапись

Простой учебный сайт для онлайн-записи к врачу.

## Как запустить
1. Откройте репозиторий на GitHub.
2. Нажмите **Code → Codespaces → Create codespace on main**.
3. В открывшемся окне откройте Terminal.
4. Выполните команду: `mvn spring-boot:run`
5. Откройте вкладку **Ports**, найдите порт **8080** и нажмите **Open in Browser**.

## Демо-вход
- Администратор: `admin` / `admin123`
- Врач: `doctor1` / `doctor123`
- Пациент: зарегистрируйтесь на сайте.

## Возможности
- Пациент регистрируется, выбирает врача, записывается и отменяет свою запись.
- Врач просматривает расписание и меняет статус приёма.
- Администратор добавляет врачей и просматривает пользователей и записи.

## База данных
Используется H2 — отдельная установка базы данных не нужна. Это учебный демонстрационный проект, не предназначенный для хранения реальных медицинских данных.
